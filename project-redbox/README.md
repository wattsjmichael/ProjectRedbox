# Project Redbox

Project Redbox is a top-down dark science-fiction action roguelite by Dadbod Studios. It combines deliberate three-step weapon combos, randomized loot, persistent Hunter profiles, an evolving Core support module, and structured runs through The Wastes.

The game is built with TypeScript, Vite, and Phaser. Run it locally with `npm run dev`; validate a production build with `npm run build`.
