# Project Redbox Documentation

**Last Updated:** 2026-08-03

This directory is the living documentation set for Project Redbox. Source code remains authoritative for implemented behavior; design documents describe intent and must be updated alongside feature changes.

## Status Legend

- **Implemented:** present and usable in the current repository.
- **In progress:** present but incomplete, temporary, or awaiting polish.
- **Planned:** accepted direction, not yet implemented.
- **Proposed:** under consideration and not committed to scope.
- **Cut:** deliberately removed from current scope.

## Open Decisions

- Final public game name and final public-facing name for the Core companion system.
- Premium, Early Access, or other release model; full release versus Early Access timing.
- Final production art direction and asset-production pipeline.
- Steam price, demo timing, and browser-demo scope.
- Whether the current persistent inventory ships in the initial public scope (it is implemented today).
- Target run duration: current structured short-form runs versus a move toward roughly 30 minutes.
- Controller-support and Steam Deck verification deadlines.
- Multiplayer scope; no multiplayer exists today.
- Longer-term console scope and platform order.
