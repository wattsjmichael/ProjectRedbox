# Project Redbox Roadmap

**Last Updated:** 2026-08-03  
**Status:** Living roadmap; milestones have no committed dates.

## Current Version

The latest named sprint is **v0.13.3 — Suit Up**. Implemented foundations include local Hunter profiles, Hub onboarding, persistent inventory/equipment, Core feeding and evolution, Hunter levels and two drop tiers, armor data/equipping, five manual-combo weapons, Basic/Fast/Tank/Elite enemies, the Wyrm, and the gated Wastes biome. Art remains largely temporary.
