- [ ] Complete Steam Direct registration and required business/tax/banking steps.
- [ ] Create the app and confirm developer/publisher display names.
- [ ] Finalize title, one-line pitch, short description, long description, feature bullets, and content disclosures.
- [ ] Choose accurate tags, genres, supported languages, platform support, and system requirements.
- [ ] Export all required capsule/library assets. **Verify against current Steamworks documentation before export.**

- [ ] Add Dadbod Studios website, social, and support links.

- [ ] Submit the store page for review, resolve feedback, and publish Coming Soon.

## Playable Build Requirements

- [ ] Configure depots/branches and upload a clean production build.
- [ ] Confirm launch options, redistributables, save locations, input, fullscreen/window behavior, and crash-free startup.
- [ ] Remove or disable production developer tools.

## Eventual Launch Requirements

- [ ] Confirm release model, price, date/window, regional pricing, and launch discount.
